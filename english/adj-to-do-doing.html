be + adj. + to do / doing

你的理解对：形容词后面默认接 to do（It is important to do sth）。而 be busy doing 这类「例外」其实有一条统一的规律——形容词后面藏着一个介词。看懂这一点，例外就不用死记了。

默认：adj. + to do

important / necessary / easy / hard / possible / kind / happy / glad / sorry / ready / able / eager / willing …

  • It is important to sleep early.
  • I'm glad to see you.

例外：adj. + (介词) + doing

busy / worth
good at / interested in / fond of / tired of / afraid of / used to …

  • She is busy doing homework.
  • The film is worth seeing.
生活比喻：介词是一个「只收名词的门卫」。
形容词后面如果直接跟动词，就用 to 牵着它：happy to see。
可一旦中间站了个介词（at / in / of / to …），门卫只放名词进门——动词必须穿上 -ing 这件「名词外套」（动名词）才能进去：good at swimming。
busy 和 worth 的门卫是隐形的：看不见，但它在。

一步一步看①：adj. + to do 的三种句型

一步一步看②：例外的秘密——门卫（介词）

判断方法：只问一个问题

形容词后面有没有介词？（包括隐形的 busy (in)、worth）
没有 → to do
important to do · happy to do · ready to do · easy to read
有 → doing
good at doing · used to doing · busy doing · worth doing

⚠ 小心 to 的两种身份：happy to help 里的 to 是不定式符号；used to / be devoted to / be close to 里的 to 是介词，后面要 doing。检验法：to 后面能换成名词吗？used to the noise ✓ → 是介词。

同一个词，两种用法：意思不一样

有几个形容词既能 + to do，也能 + 介词 + doing，考试最爱考它们的区别。

常见误区

  • ✗ He is busy to do his homework. → ✓ busy doing。busy 后面有隐形的 in。busy 后面接名词时用 busy with sth。
  • ✗ The museum is worth to visit / worth being visited. → ✓ worth visiting。主动形式就表达被动意思（「值得被参观」）。
  • ✗ I'm used to get up early.（想说「习惯早起」）→ ✓ used to getting up。这里的 to 是介词。
  • ✗ This question is easy to answer it. → ✓ 去掉 it。主语 this question 就是 answer 的对象，后面不再重复。
  • ✗ It's kind for you to help me. → ✓ kind of you。夸/批评「人的品质」（kind, nice, clever, careless, rude）用 of；其他（important, easy, necessary）用 for。
一句话总结：形容词后面直接跟动词 → to do；形容词后面有介词（看得见的 at / in / of / used to，或看不见的 busy、worth）→ doing。
