文言五大句式：一句口诀记住

判断、被动、省略、倒装、固定句式，条目多、例句杂，很难背。换个角度：别背「定义」，记住翻译时各要做什么动作。

生活比喻：把古人的「快递包裹」拆开整理

古人寄来的句子，和现代汉语比，总有几处「不对劲」：少了「是」、少了「被」、缺了东西、东西放错了位置，或者用的是一套固定的老包装。

五种句式，就是拆包时的五个整理动作。认出是哪一种，就知道该怎么动手。

② 看句子怎么「变」成现代汉语

选一个例句，一步一步看：先找标志，再做动作，最后得到译文。

标志词补出 / 换上的字

③ 五类分口诀（点开看细节）

背诵模式：口诀里的关键字会被遮住，先自己说出来，再点一下揭开核对。
判

判断句 → 加「是」

口诀：者也一对，乃则即皆，为是与非，没标志靠语意▶

说「A 是 B」（或「A 不是 B」）的句子。数一数：1 对 + 4 个副词 + 2 个动词 + 1 个否定 + 光杆，一共 5 种。

标志例句
者……也陈胜者，阳城人也。（只用「也」：夫战，勇气也；句尾「者也」：莲，花之君子者也）
乃 则 即 皆当立者乃公子扶苏。／此则岳阳楼之大观也。／夫六国与秦皆诸侯。
为 是如今人方为刀俎，我为鱼肉。／同行十二年，不知木兰是女郎。
非（否定）城非不高也，池非不深也。→ 不是
无标志刘备天下枭雄。（靠语意：刘备是天下的英雄）

⚠ 陷阱：谓语前的「是」多半是代词「这」，不是判断词。如「所在皆是也」＝到处都是这样。

被

被动句 → 加「被」

口诀：于、为、见、被四个字，再加意念没标志▶

主语是挨打的一方。四个标志字可以单用，也可以配成组合：受……于、为……所、见……于。「于」「为」后面跟的是动手的人，翻译时提到动词前。

标志例句
于／受……于不能容于远近。／受制于人。
为／为……所身死国灭，为天下笑。／恐为操所先。
见／见……于吾长见笑于大方之家。
被予犹记周公之被逮。
无标志（意念被动）荆州之民附操者，逼兵势耳。（＝被兵势所逼）

⚠ 陷阱：动词前的「见」有时表示「对我」，是客气话，不表被动。如「冀君实或见恕也」＝希望您或许能原谅我（今天的「见谅」）。

省

省略句 → 补

口诀：主谓宾介加修饰中心；宾语多补之，介词多补于、以▶

句子成分被省掉了，翻译时省啥补啥，补的字放在括号里。

省了什么例句（括号里是补出的）
主语永州之野产异蛇，（蛇）黑质而白章。（承前省；还有承后省、自述省、对话省）
谓语一鼓作气，再（鼓）而衰，三（鼓）而竭。
宾语拜（之）为上卿。／竖子不足与（之）谋。／投（之）以骨。
介词赐之（以）彘肩。／将军战（于）河北。
修饰语／中心词（吾）妾之美我者。／杀一无罪（人）。

⚠ 介词「以、为、与」后面的宾语「之」最常被省，看到「与谋」「以为」这类，想想后面是不是缺了「之」。

倒

倒装句 → 调

口诀：宾语往前跑，定、状、主往后跑▶

四种倒装里只有宾语是「前置」，另外三个都是「后置」。翻译时把它们调回现代汉语的位置。

宾语前置四条路：否定句代词、疑问代词、介词宾语、之、是提宾

类型例句 → 正常语序
否定句＋代词宾语莫我肯顾 → 莫肯顾我／忌不自信 → 不自信己／未之有也 → 未有之也
疑问代词作宾语大王来何操 → 操何／沛公安在 → 在安／彼且奚适也 → 适奚
介词宾语吾谁与归 → 与谁归／何以自托于赵 → 以何／是以 → 以是（因此）
之、是 提宾宋何罪之有 → 有何罪／惟命是听 → 惟听命
定语后置三式：中＋定＋者（楚人有涉江者）；中＋之＋定（蚓无爪牙之利）；中＋（之）＋数量（马之千里者／白璧一双）
状语后置「于／以」介宾短语放在动词后：青取之于蓝 → 于蓝取之／覆之以掌 → 以掌覆之
主谓倒装为了强调谓语：甚矣，汝之不惠 → 汝之不惠甚矣／快哉此风

⚠ 否定句宾语前置要同时满足两条：有否定词（不、未、毋、莫）＋宾语是代词（我、之、己……）。

固

固定句式 → 套

口诀：按译法分五组——比较、揣测、反问、处置、其他▶

像一套现成的「模具」，整体套上现代汉语的固定说法即可，不要逐字硬译。

组别句式 → 套译
比较孰与、何如 → 跟……比，谁更……（吾孰与城北徐公美）／与其……孰若、与其……宁 → 与其……不如（与其坐而待亡，孰若起而拯之）
揣测得无……乎（耶）→ 该不会……吧（得无教我猎虫所耶）／无乃……与 → 恐怕……吧（无乃尔是过与）
反问何（以）……为、奚以……为 → 为什么要……呢（何以伐为）／不亦……乎 → 不是……吗（不亦乐乎）／岂……哉、独……哉 → 难道……吗
处置如……何、奈……何、若……何 → 把……怎么办（如太行、王屋何）／以……为 → 把……当作（以荆卿为计）
其他无以 → 没有用来……的办法（无以至千里）／……之谓也 → 说的就是……／唯……是 → 只……（惟利是图）

⚠ 「何以……为」里的「为」是句末语气词（呢），不是「为了」。

④ 自己试试：句式侦探

读句子，判断它属于哪一种句式。答完会高亮破案线索。句子都来自讲义。

⑤ 常见误区

误区 1：看到「是」就当判断句。
谓语前的「是」多是代词「这」：「所在皆是也」「是以」。木兰诗里的「木兰是女郎」才是判断词。
误区 2：看到「见」「为」就当被动。
「见恕」「见谅」中的「见」＝对我；「以……为」＝把……当作；「何以……为」的「为」是语气词。看后面跟的是不是动手的人。
误区 3：倒装全是「往前放」。
只有宾语前置是往前，定语、状语、主语都是后置。「青取之于蓝」是状语后置，不是宾语前置。
一句话：判被省倒固，加是加被补调套——认出句式，就知道翻译时该做哪个动作。
