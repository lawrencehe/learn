# learn-animate：生成动画学习页

## 流程

1. **确定主题**：从用户的话里提炼出要学的知识点。若主题过大（如"学习机器学习"），选一个最核心的入门切口来做，并在回复里说明可以继续深入哪些子主题；不要为此反复追问。
2. **确定类目**：按 `.claude/rules/learn-html.md` 的分类表归入 `math` / `english` / `model` / `tech` 之一。都不合适时先问用户。
3. **查重**：`ls -R /home/opc/learn/`。已有同主题页面时，若用户想深入/补充，就在原文件上扩展；否则新建。
4. **设计讲解脚本**（先在心里列好，不必输出给用户）：
   - 一个生活化比喻
   - 3~6 个分步动画场景，每步一句说明
   - 至少一个可交互的「自己试试」环节
   - 常见误区 1~3 条
   - 一句话总结
   - 至少 5 道练习题（含答案与解析）
   - 列出页面所有可变状态及其初始值，供重置使用
5. **编写 HTML**：写入 `/home/opc/learn/<类目>/<英文-kebab-case>.html`（目录不存在就先创建），严格遵守 `.claude/rules/learn-html.md`，尤其是：
   - 全局「重置」按钮 + 每个动画模块的局部重置
   - 页面末尾的「练习」区（即时反馈、解析、得分、重做）
6. **自查**：按规则文件的「收尾自查」逐项检查，重点验证"操作后点重置能回到初始状态"和"习题答案正确"。
7. **发布**：在 `/home/opc/learn` 下运行 `npm run deploy`，成功后 `git add -A && git commit -m "<类目>: <主题>"`。失败时把报错告诉用户，不影响本地交付。
8. **交付**：回复用户，内容简短：
   - 线上链接：`https://up.yiwei.website/<类目>/<文件名>`（不带 `.html`）
   - 本地链接：`file:///home/opc/learn/<类目>/<文件名>.html`
   - 一两句说明页面里有什么（比喻是什么、有哪几段动画/交互、几道练习题）
   - 可选：可以继续深入的相关主题

## 注意

- 讲解正确性优先于花哨效果；不确定的事实不要编造。
- 页面要能离线打开（外部字体加载失败时有系统字体回退，核心动画不依赖 CDN）。
- 若用户是在远程机器上而本地浏览器无法直接打开 `file://` 链接，可提示用 `python3 -m http.server -d /home/opc/learn 8000` 起一个临时服务后访问。
