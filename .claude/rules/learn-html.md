# 动画学习页质量标准

适用于 `/home/opc/learn/**/*.html` 的所有学习页。

## 分类存放（必须）

每个页面按内容归入一个类目，存放在对应子目录：

| 类目 | 目录 | 内容范围 |
|---|---|---|
| math | `/home/opc/learn/math/` | 数学：代数、几何、概率统计、微积分、线性代数等 |
| english | `/home/opc/learn/english/` | 英语：单词辨析、语法、发音、习惯用法等 |
| model | `/home/opc/learn/model/` | AI 模型：机器学习、神经网络、大模型、训练与推理原理等 |
| tech | `/home/opc/learn/tech/` | 计算机技术：网络协议、数据结构与算法、操作系统、编程、工具等 |

- 跨类目时，按「用户最想弄懂的那部分」归类（例如"神经网络里的矩阵乘法"→ 想懂矩阵归 math，想懂网络归 model）。
- 四个类目都不合适时，先问用户：归入最接近的类目，还是新建类目。新建后要把它补进本表和 `CLAUDE.md`。
- 类目由统一导航条显示（见下节），页面里不要再放 `tech` 之类的类目标签。

## 统一外壳与风格（必须）

全站共用一套「外壳」，由 `scripts/shell.mjs` 生成，`npm run build` 时自动写进每个页面 `<body>` 的开头（源文件也会同步）。页面只负责内容。

- **从骨架起步**：新页面复制 `.claude/skills/learn-animate/template.html` 再改，它已经包含变量映射、分步动画模块（含局部重置）、通用练习组件和重置约定。
- **导航条**：顶部固定栏，依次是 logo（回首页）› 类目（回类目页）› 页面标题，右侧是全局「↺ 重置」。页面**不要**自己写顶栏、返回按钮、浮动重置按钮；顶部 52px 被导航条占用，不要放 `top:0` 的 fixed/sticky 元素。
- **完整文档**：必须有 `<!doctype html>`、`<head>`、`<body>`，否则导航条插不进去（build 会报 ⚠）。
- **颜色**：背景、文字、边框等中性色一律用站点变量，不要自己再定义一套：

  | 变量 | 用途 |
  |---|---|
  | `--up-bg` / `--up-surface` / `--up-surface-2` | 页面背景 / 卡片 / 次级底色（画布、代码块） |
  | `--up-ink` / `--up-muted` / `--up-line` | 正文 / 次要文字 / 边框分隔线 |
  | `--up-accent` / `--up-accent-soft` | 类目主色（按钮、选中态、强调边框）/ 它的浅底 |
  | `--up-ok` / `--up-bad` | 答对 / 答错 |
  | `--up-font` / `--up-mono` | 正文和标题字体 / 等宽字体 |
  | `--up-radius` / `--up-shadow` | 卡片圆角 / 阴影 |

  做法：页面 `:root` 里写 `--bg:var(--up-bg); --ink:var(--up-ink); --accent:var(--up-accent)` 这类映射，再只为**内容语义**另加颜色（如"红节点""第 1 层""begin/start"），这些语义色要同时给出深色模式的值。
- 类目主色只用于 UI 强调；如果它和内容语义色撞色（例如英语页主色是绿色，内容里绿色又表示"正确"），内容那一方换个颜色。主色背景上的文字用 `var(--up-surface)`，不要写死 `#fff`（深色模式下主色很浅，白字会看不清）。
- **字体**：正文和标题用 `var(--up-font)`，数字/代码用 `var(--up-mono)`。只有内容确实需要时才用专门字体（音标、数学公式、英文展示大字），并带系统字体回退。

## 讲解原则：浅显易懂

- 面向零基础读者，默认用中文（`<html lang="zh-CN">`），术语首次出现时附一句大白话解释。
- 先给**生活化比喻**建立直觉，再讲正式定义，最后讲细节/边界情况。
- 一屏只讲一个要点；按「是什么 → 为什么 → 怎么工作 → 常见误区 → 一句话总结 → 习题」组织。
- 能用图和动画表达的，不用大段文字。每段文字尽量不超过 3 行。

## 动画要求

- 动画必须**服务于理解**：展示过程、变化、因果、对比，而不是装饰。
- 关键过程做成**分步动画**，提供「上一步 / 下一步 / 播放」控制，旁边配当前步骤的文字说明。
- 能交互的就交互：滑块调参数、点击切换场景、拖拽、输入试一试，让用户亲手验证。
- 用 CSS 动画/过渡、inline SVG、Canvas 或原生 JS 实现；动画节奏放慢（单步 ≥ 600ms），便于看清。
- 尊重 `prefers-reduced-motion`：开启时减少或去掉自动播放动画，保留分步按钮。

## 重置按钮（必须）

- 全局「重置」按钮由导航条提供，位置全站统一（顶栏右侧），页面不要再放自己的全局重置按钮。
- 页面必须定义 **`window.resetPage()`**，导航条按钮会调用它，然后自动滚回顶部。它要把整页恢复到**刚打开时的初始状态**：所有动画回到第 1 步并停止播放、滑块/输入框/开关恢复默认值、已切换的场景恢复默认、习题清空作答与得分、展开的答案收起。
- 用骨架里的通用练习组件时，页面只需定义 `window.pageReset()`（依次调用各模块的 `reset()`），组件会把「`pageReset()` + 清空练习」包装成 `window.resetPage`。
- 每个分步动画模块也各自带一个局部「重置」按钮，只重置该模块。
- 实现方式：每个模块提供自己的 `reset()`，在初始化时也调用它；全局重置依次调用所有模块的 `reset()`。不要用 `location.reload()` 代替。
- 状态全部集中在 JS 变量里，初始值写在一处，避免"重置漏掉某个状态"。

## 习题（必须）

- 页面末尾设「练习」区，优先用骨架里的通用练习组件（`window.LQ_ITEMS` 填题目即可），至少 **5 道题**，由易到难，题型混合：选择题、判断题，以及适合该主题的填空/计算/排序/拖拽题。
- 每题作答后即时反馈对错，并给出**解析**（为什么对、错在哪，必要时引用前面的动画步骤）。
- 显示总得分（如 `4 / 5`），并提供「重做练习」按钮（只清空习题）；全局重置也会清空习题。
- 至少 1 道题考查「常见误区」，至少 1 道题需要迁移应用（换个场景用同一知识点）。
- 讲读音、发音的页面必须配真实音频：例词可点读，并能切换美音/英音和语速；用 `npm run tts` 预先生成并内嵌，不用浏览器 speechSynthesis。
- english 类目的习题以真实例句为主（选词填空、改错、情景选择）；math 类目包含至少 1 道动手计算题。

## 技术约束

- **单文件自包含**：CSS、JS 全部内联；不依赖本地其他文件。
- 外部脚本只在必要时用，且仅限 cdnjs.cloudflare.com / cdn.jsdelivr.net/npm/ / unpkg.com，必须写死精确版本号；字体可用 Google Fonts，并提供系统字体回退（离线也能正常显示）。
- 颜色定义为 `:root` 上的 CSS 变量（中性色映射到 `--up-*`，见「统一外壳与风格」），并支持深色模式（`@media (prefers-color-scheme: dark)`）。
- 响应式：手机宽度下可用，左右留 16px 边距，无横向滚动。
- `<title>` 用 2~6 个字/词的主题名，例如「TCP 滑动窗口」。
- 必须有 `<meta name="description" content="...">`，一句话说明本页讲什么（网站目录页会显示它）。
- 不使用 localStorage 存关键内容；页面打开即完整可用。

## 收尾自查

- `npm run build` 没有 ⚠ 警告（会同时把导航条写进页面，之后本地打开也能看到）。
- 内联 JS 无语法错误（有 node 时用 `node --check` 检查抽出的脚本）。
- 所有按钮可用；操作一番后点导航条上的「重置」，确认页面与刚打开时一致。
- 习题的正确答案与解析经过核对，没有错题。
- 深浅色模式下文字都清晰可读。
