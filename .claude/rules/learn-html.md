# 动画学习页质量标准

适用于 `/home/opc/learn/**/*.html` 的所有学习页。

## 分类存放（必须）

每个页面按内容归入一个类目，存放在对应子目录：

| 类目 | 目录 | 内容范围 |
|---|---|---|
| math | `/home/opc/learn/math/` | 数学：代数、几何、概率统计、微积分、线性代数等 |
| english | `/home/opc/learn/english/` | 英语：单词辨析、语法、发音、习惯用法等 |
| model | `/home/opc/learn/model/` | AI 模型：机器学习、神经网络、大模型、训练与推理原理等 |
| tech | `/home/opc/learn/tech/` | 计算机技术：网络协议、数据结构与算法、操作系统、编程、工具等 |

- 跨类目时，按「用户最想弄懂的那部分」归类（例如"神经网络里的矩阵乘法"→ 想懂矩阵归 math，想懂网络归 model）。
- 四个类目都不合适时，先问用户：归入最接近的类目，还是新建类目。新建后要把它补进本表和 `CLAUDE.md`。
- 页面顶部显示类目标签（如 `tech`），方便识别。

## 讲解原则：浅显易懂

- 面向零基础读者，默认用中文（`<html lang="zh-CN">`），术语首次出现时附一句大白话解释。
- 先给**生活化比喻**建立直觉，再讲正式定义，最后讲细节/边界情况。
- 一屏只讲一个要点；按「是什么 → 为什么 → 怎么工作 → 常见误区 → 一句话总结 → 习题」组织。
- 能用图和动画表达的，不用大段文字。每段文字尽量不超过 3 行。

## 动画要求

- 动画必须**服务于理解**：展示过程、变化、因果、对比，而不是装饰。
- 关键过程做成**分步动画**，提供「上一步 / 下一步 / 播放」控制，旁边配当前步骤的文字说明。
- 能交互的就交互：滑块调参数、点击切换场景、拖拽、输入试一试，让用户亲手验证。
- 用 CSS 动画/过渡、inline SVG、Canvas 或原生 JS 实现；动画节奏放慢（单步 ≥ 600ms），便于看清。
- 尊重 `prefers-reduced-motion`：开启时减少或去掉自动播放动画，保留分步按钮。

## 重置按钮（必须）

- 页面必须有一个**全局「重置」按钮**，始终容易找到（如固定在页面顶部栏或右下角）。
- 点击后整页恢复到**刚打开时的初始状态**：所有动画回到第 1 步并停止播放、滑块/输入框/开关恢复默认值、已切换的场景恢复默认、习题清空作答与得分、展开的答案收起，并滚动回页面顶部。
- 每个分步动画模块也各自带一个局部「重置」按钮，只重置该模块。
- 实现方式：每个模块提供自己的 `reset()`，在初始化时也调用它；全局重置依次调用所有模块的 `reset()`。不要用 `location.reload()` 代替。
- 状态全部集中在 JS 变量里，初始值写在一处，避免"重置漏掉某个状态"。

## 习题（必须）

- 页面末尾设「练习」区，至少 **5 道题**，由易到难，题型混合：选择题、判断题，以及适合该主题的填空/计算/排序/拖拽题。
- 每题作答后即时反馈对错，并给出**解析**（为什么对、错在哪，必要时引用前面的动画步骤）。
- 显示总得分（如 `4 / 5`），并提供「重做练习」按钮（只清空习题）；全局重置也会清空习题。
- 至少 1 道题考查「常见误区」，至少 1 道题需要迁移应用（换个场景用同一知识点）。
- english 类目的习题以真实例句为主（选词填空、改错、情景选择）；math 类目包含至少 1 道动手计算题。

## 技术约束

- **单文件自包含**：CSS、JS 全部内联；不依赖本地其他文件。
- 外部脚本只在必要时用，且仅限 cdnjs.cloudflare.com / cdn.jsdelivr.net/npm/ / unpkg.com，必须写死精确版本号；字体可用 Google Fonts，并提供系统字体回退（离线也能正常显示）。
- 颜色定义为 `:root` 上的 CSS 变量，并支持深色模式（`@media (prefers-color-scheme: dark)`）。
- 响应式：手机宽度下可用，左右留 16px 边距，无横向滚动。
- `<title>` 用 2~6 个字/词的主题名，例如「TCP 滑动窗口」。
- 必须有 `<meta name="description" content="...">`，一句话说明本页讲什么（网站目录页会显示它）。
- 网站发布时会在页面左下角注入「← 类目」返回按钮，页面自身左下角不要放固定元素。
- 不使用 localStorage 存关键内容；页面打开即完整可用。

## 收尾自查

- 内联 JS 无语法错误（有 node 时用 `node --check` 检查抽出的脚本）。
- 所有按钮可用；操作一番后点全局「重置」，确认页面与刚打开时一致。
- 习题的正确答案与解析经过核对，没有错题。
- 深浅色模式下文字都清晰可读。
