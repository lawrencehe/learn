绝对值与相反数

相反数是“照镜子”，绝对值是“量距离”。这一页讲清 −(−(−3)) 怎么化简、|x| = 5 为什么有两个答案、−7 和 −3 谁大、−|−4| 和 −(−4) 有什么不同。学完可以去 七、专项训练 随机刷题。

生活比喻：从家门口出发
把家门口当作 0，向东为正，向西为负。
相反数：同样走 3 步，一个向东（+3）、一个向西（−3），它们方向相反、步数一样。
绝对值：只问“离家多远”，不管往哪边走。+3 和 −3 都离家 3 步，所以 |3| = |−3| = 3。

一、相反数：在 0 处放一面镜子

只有符号不同、数字一样的两个数，叫互为相反数。在数轴上，它们正好在 0 的两边，像照镜子一样对称。

⚠ “−a”读作“a 的相反数”，不一定是负数：a = −5 时，−a = −(−5) = 5，是正数。把滑块拖到负数看看。

二、一层层套负号：每套一层就翻一次面

“−( )”就是“求相反数”，在数轴上翻到镜子另一边。套两层就翻回来了。“+( )”什么都不改变。

口诀：数负号 偶数个“−” → 正 奇数个“−” → 负 “+”不用管

三、绝对值：到 0 的距离

一个数在数轴上离 0 有多远，就是它的绝对值，记作 |a|。距离只有长短、没有方向，所以绝对值永远不会是负数。

正数的绝对值 = 它本身：|5| = 5 负数的绝对值 = 它的相反数：|−5| = 5 0 的绝对值 = 0

四、反过来问：|x| = 5，x 是几？

问的是“离 0 有 5 格的点在哪”，答案是两边各一个。拖动滑块试试，特别看看 0 和负数。

五、两个负数比大小：绝对值大的反而小

比大小只看数轴上谁更靠右。−7 的绝对值比 −3 大，但它在更左边，所以 −7 < −3。就像欠 7 块钱比欠 3 块钱更“穷”。

六、算式里的绝对值号：像一副括号

绝对值号 | | 和括号一样，先算里面，再取绝对值。只有夹在里面的东西才受影响，外面的负号原样保留。

✗ −|−4| = 4　✓ −|−4| = −4
绝对值号只管里面的 −4，把它变成 4；最前面的“−”在绝对值号外面，要保留。对比：−(−4) = 4，那是括号，不是绝对值号。
✗ |3 − 8| = |3| − |8| = −5　✓ |3 − 8| = |−5| = 5
绝对值号里有算式，要先算出结果再取绝对值。|3 − 8| 一定 ≥ 0，算出负数就肯定错了。
✗ |x| = 5，所以 x = 5　✓ x = 5 或 x = −5
离 0 有 5 格的点，0 的左右两边各有一个，漏掉负的那个是最常见的错误。
✗ −a 一定是负数　✓ 要看 a 本身
−a 是“a 的相反数”。a 是负数时，−a 反而是正数；a = 0 时，−a = 0。

一句话总结

相反数是在 0 处照镜子：只翻符号，数字不变，套几层负号就数几个“−”（偶正奇负）；绝对值是到 0 的距离：永远 ≥ 0，|x| = 5 有两个解，两个负数比较时绝对值大的反而小。
