根据数轴化简绝对值

试卷1 第 20 题。看到 |b + c| 这种“绝对值号里装着式子”，不能直接把竖线擦掉。秘诀一句话：先看里面是正是负，再决定怎么脱掉绝对值号。

原题（试卷1 第 20 题）

有理数 a、b、c 在数轴上对应的点如图所示（从左到右依次是 c、a、0、b），已知 |c| > |b| > |a|，化简：|b + c| − |a − c|。

答案：−a − b

卷面上：第一次直接擦掉竖线写成 b + c − a − c（错）；第二次推到了 −b − a，可“答”里抄成了 −b − c。思路对了一半，最后一步也要核对。

生活比喻：绝对值号是一台“去负号机”。
放进去一个正数，原样出来；放进去一个负数，它会把负号去掉再吐出来，也就是“套一个负号翻成正的”：|−5| = −(−5) = 5。
所以机器里装着式子时，要先弄清楚这个式子算出来是正还是负，才知道机器会不会给它“翻面”。

一步一步看：先判号，再脱壳

为了看清楚，取一组满足条件的数：c = −6，a = −1，b = 4（|c| = 6 > |b| = 4 > |a| = 1）。

方法：三步走

  1. 看图判号：逐个判断绝对值号里的式子是正还是负（判号口诀见下）。
  2. 脱绝对值号，一律先加括号：里面是正 → |式子| = (式子)；里面是负 → |式子| = −(式子)。
  3. 去括号、合并：括号前是负号，括号里每一项都要变号；最后把能抵消的抵消掉。
加法 p + q 怎么判号
同号：跟着它们的符号。
一正一负：跟着离 0 远的那个（绝对值大的）。
例：b + c，c 离 0 更远 → 负。
减法 p − q 怎么判号
看数轴左右：右边的减左边的 → 正；左边的减右边的 → 负。
例：a − c，a 在 c 右边 → 正。

自己试试：判号实验室

拖动滑块改 a、b、c 的位置，再点一个式子。箭头从起点出发，落在 0 右边就是正，左边就是负。

常见误区

  1. 直接擦掉竖线：|b + c| 写成 b + c。只有里面是正的（或 0）才能这么做。
  2. 翻面时忘了加括号：|b + c| = −b + c ✗，应该是 −(b + c) = −b − c，每一项都变号。
  3. 减号后面的绝对值也要加括号：− |a − c| = −(a − c) = −a + c，写成 −a − c 就错了。
  4. 判号只看字母前面的符号：b + c 看起来“全是加号”，但 c 本身是负数，结果是正是负要看数轴。
一句话总结：绝对值号里是式子时，先用数轴判号（加法看谁离 0 远，减法看谁在右边），正的原样加括号，负的前面添负号再加括号，最后去括号合并。
