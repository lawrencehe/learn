一步一步：从关键词认出题型

读题时先圈出橙色的“信号词”，题型就出来了。

五种题型速查

第 4 题

① 运算程序找周期

信号：“返回进行第二次运算”“第 2025 次输出”

方法：老实算到出现重复 → 一组几个 → 次数 ÷ 组长看余数。

坑：余 0 是组里最后一个；输入的数不算输出；有前奏要先减掉。

去学：运算程序找周期 →
第 14 题

② 余数相同，求除数

信号：“分别除以同一个数”“余数都相同”

方法：两两相减 → 差的最大公因数 → 按条件筛选、验算。

坑：直接求原数的公因数；忘了排除 1（余数为 0）。

去学：余数相同，求除数 →
第 19 题

③ 分数应用：进价、提价、损耗

信号：“占剩下的”“比……多 13”“提价 34”“有 16 的损耗”

方法：逐句找单位“1”；多 → ×(1 + 分率)，损耗 → ×(1 − 分率)；赚 = 收入 − 成本。

坑：“剩下的”当总数；3 ÷ 13；损耗算进成本。

去学：水果进价、提价与损耗 →
第 20 题

④ 行程：提速几分之几 → 时间比

信号：“车速提高 17”“提前……到达”“按原速行驶 120 千米后再提速”

方法：速度 n : (n+1) → 时间 (n+1) : n；提前的时间 = 1 份；分段时只算提速那段。

坑：以为时间也少 17；把第二天省的 20 分算成全程的。

去学：提速几分之几：时间比 →
第 21 题

⑤ 数轴：非负数和为 0 + 火车模型 + 年龄

信号：“|a − 5| + (b − 23)² = 0”“车头到 A 时车尾在 C”“我若是你这么大”

方法：非负数相加为 0 → 各自为 0；不变的长度左右各挪一次 → 四点等距，一段 = 总长 ÷ 3。

坑：÷2；“还要 42 年才出生”写成 +42。

去学：数轴上的火车与年龄 →

一句话总结：这五题都在考“看不变的东西”：周期不变、余数一样、单位“1”跟着句子走、路程不变时速度和时间反比、火车长和年龄差不变——找到不变量，题就破了。
