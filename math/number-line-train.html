数轴上的火车与年龄

试卷第 21 题。三个小问其实是一个套路：一段长度不变的“火车”在数轴上左右挪，挪出来的几个点间隔相等。年龄差也是这样一列不变的火车。
← 试卷3错题总览

原题（第 21 题）

在数轴上点 A 表示数 a，点 B 表示数 b，|a − 5| + (b − 23)² = 0。

（1）a = ＿，b = ＿；

（2）一个玩具火车放在数轴上，车头在点 C，车尾在点 D。将火车沿数轴左右水平移动，当车头移动到点 A 时，车尾恰好与点 C 重合；当车尾移动到点 B 时，车头正好与点 D 重合。① 玩具火车长＿个单位长度；② C 点表示的数是＿，D 点表示的数是＿；

（3）妙妙问爷爷：“您今年多少岁了？”爷爷说：“我若是你现在这么大，你还要 42 年才出生；你若是我现在这么大，我已经 120 岁，是老寿星了！”请借助数轴算一算，爷爷和妙妙现在分别多少岁？

答案：（1）a = 5，b = 23；（2）① 6　② C = 11，D = 17；（3）爷爷 66 岁，妙妙 12 岁。

第（1）问：两个“不会是负数”的数加起来等于 0

|a − 5| 是绝对值，一定 ≥ 0；(b − 23)² 是平方，也一定 ≥ 0。

两个不会是负数的数加起来是 0，只可能两个都是 0（就像两个人各掏出不是负数的钱，加起来 0 元，那每人都掏了 0 元）。

a − 5 = 0 → a = 5　　b − 23 = 0 → b = 23

生活比喻：挪一根尺子量距离。
手里一根尺子（火车），往左挪一次、往右挪一次，每次正好挪一个尺子长。从 A 到 B 一共被分成了三段一样长的距离：A→C、C→D、D→B。

第（2）问：开火车

第（3）问：年龄差就是一列火车

方法：画出四个等距点

  1. 找出那段不变的长度：火车长、年龄差。
  2. 按题意左挪一次、右挪一次，在数轴上标出四个点：左端、两个中间点、右端。
  3. 四个点间隔相等：一段 = (右端 − 左端) ÷ 3。
  4. 从左端加一段、两段，得到中间两点。“还要 42 年才出生”记作 −42。

自己试试：换一组爷爷的话

常见误区

① 以为 A 到 B 只有两段：火车挪了两次，但 A、C、D、B 之间是三段（C→D 本身就是车长）。18 ÷ 2 = 9 是错的，18 ÷ 3 = 6 才对。

② “还要 42 年才出生”写成 +42：还没出生，在数轴 0 的左边，是 −42。所以全长是 120 − (−42) = 162，不是 120 − 42。

③ 忘了年龄差不变：不管过去还是将来，爷爷永远比妙妙大同样多岁——这就是那列长度不变的火车。

一句话总结：一段长度不变的东西（火车、年龄差）左挪一次、右挪一次，就在数轴上切出三段相等的距离：一段 = 总距离 ÷ 3。
